# Calculadora Financeira em Python

Calculadora financeira desenvolvida em Python como projeto de estudo, com o objetivo de praticar conceitos fundamentais e intermediários da linguagem.

## Funcionalidades

O programa permite:

- Calcular o valor total de uma compra
- Calcular descontos
- Calcular aumentos percentuais
- Calcular lucro ou prejuízo
- Calcular margem de lucro
- Somar múltiplas despesas
- Gerar um resumo financeiro com receitas, despesas e saldo

## Conceitos praticados

Durante o desenvolvimento foram utilizados:

- Funções
- Parâmetros e argumentos
- Funções lambda
- `*args`
- Desempacotamento de listas
- Listas
- `append()`
- Laços `for`
- Laços `while`
- Estruturas condicionais `if`, `elif` e `else`
- Entrada de dados com `input()`
- Conversão de tipos com `int()` e `float()`
- Formatação de valores com f-strings

## Como executar

É necessário ter Python instalado.

Execute o arquivo:

```bash
python calculadora.py
